# 村路平滑化（Village Path Smoothed）

[English](README.md) | **中文**

在**世界生成阶段**改写原版村庄道路。原版道路随地形逐列起落，一跳就是一整格；
本 mod 把它重建成由**台阶（底部半砖 slab，不是楼梯）**搭成的连续路面，顺向和
横向都不会出现超过**半格**的落差。爬坡时道路以"下沉路段"切入山坡、由石质包边
收住侧壁，过水处架起脚手架桥，临崖边缘种上树叶护栏。

- **服务端世界生成 mod**：装在服务端（或单人游戏）即可，客户端无需安装。
- **每世界独立开关**：创建世界界面左下角有"村路平滑化：启用"开关。点击"创建"
  时，开关值绑定到正在创建的世界（按世界名匹配），该世界首次生成区块时把开关
  写入自己的 `<世界>/village_path_smoothed.json`。已有世界、以及创建时没动过
  开关的世界，沿用各自设置或全局默认值。**世界开关优先**，全局配置只负责播种
  新世界；游戏内用 `/vps world on|off` 切换。
- **只影响新生成的区块**：与原版世界生成一致，mod 只在区块生成时起作用，
  已生成的区块保留原版道路。

## 功能

### 路面

路网掩膜从每种村庄风格的街道模板重建，然后为它求解一个高度剖面。

- **半格台阶**。相邻格顺向、横向落差都不超过半格。默认目标函数 `SMOOTH_FIRST`
  按**断崖惩罚 > 总台阶数 > 对地形的偏差**排序——"平滑"即"半格台阶越少越好"：
  候选带允许时削平短促的起伏，持续坡度按半格节奏跟随，几何上无法用半格通过的
  断崖按软约束取一次最短的原版式跳格（计入 `/vps stats`）。
- **什么算路**。掩膜是**连通的街面**：从街道 jigsaw 连接点可达的 y=0 格，加上
  装饰座位。街道模板内的农田、水渠、陶瓦镶边是景物、不是路：保留原版方块，
  writer 也不向其包边。高于景物数格的架空路仍按落差规则在那条边放落差护栏；
  景物自身高度处不加任何东西。连接点下的普通 dirt 仍算路，十字路口的接缝不会
  破洞。
- **材质**。整格路块写成**泥砖**，半格台阶仍是**泥砖台阶**，路面下方的垫方保持
  原版土径。沙漠的平滑砂岩路面与台阶不变。只有 mod 写的路面会换材质——广场、
  街件、建筑里的土径以及路面下的垫方都不改。
- **下沉路段**。连续的一格一跳坡地按半格节奏走：道路切入山坡，包边收住侧壁。
- **桥面与隧道**。填/挖都带不动的长坡变成**架空桥面**（填方上限）或
  **带顶隧道**（清方上限），不再被打散成逐格台阶。
- **逐格填挖**。填方/挖方按格判定，依据**向下探测**，从不看高度图顶：开放路面
  上方的树冠或悬空层不再强制填方，实路上方的悬挑不再强制挖方。清方与包边都不会
  替换受保护的建筑方块或非地形装饰。原始高度图仍用于偏差统计与悬空/深埋守卫，
  两者都只是观测。

### 建筑随路

在村庄包围盒冻结之前，每个可移动的 RIGID 组件被整体竖向平移，使其**原版基面**
（`主体件 minY + groundLevelDelta`）在**主门**处与道路相接——主门是离模板
`building_entrance` jigsaw 最近的真实门。

- 只有 `#minecraft:doors` 里的方块算门（高草、蕨不再算），双开门两扇都保留。
- 门口路格必须在所有受保护建筑足迹之外、不是装饰座位、且位于门墙外侧；找不到
  合格格子时组件不平移（开启 `debug.doorSigns` 时门牌写 `NO FRONT`）。
- 平移作用于整个 RIGID 组件，并同步 jigsaw junction，因此 beard 仍包在建筑
  周围；位移是种子的纯函数。
- 建筑移动后，道路按移动后的足迹再解一次；随后做第二次权威对齐，把组件对齐到
  最终路网并冻结道路。
- 悬空/深埋组件只计数（`/vps stats`），从不修复（`buildingGuard`）。

**plan A 保护建筑体本身，而不是模板包围盒。** 受保护的是模板真实放置的建筑
方块，以及沿六个轴至少五个方向在离开模板前能遇到建筑方块的内部空气（普通房间
中央算内部，开放边缘不算）。旧 bbox 里的空部分——院子、模板空角、屋檐下的
空气——不再阻止路块、垫方和清格，Y 方向也没有额外余量。模板读不出来时退回
整件 bbox，避免无法识别的模组建筑失去保护。

**街件装饰**走的是同一轮建筑流程，不是 plan A 的 bbox 障碍：

- writer 保护装饰的**实际模板方块**（含圆石/雪底座），同时照常在其下方/周围写
  路与垫方，因此 3×3 灯的空 bbox 列不再留洞。适用于所有可识别装饰，包括只贡献
  一个固定底座的房屋灯。装饰模板/池读不出来时，该件被排除出 plan A、可读方块
  照常保护（`/vps stats` 记 `resolve failed`），而不是退回整件 bbox。
- 多格装饰在 T5 把**整个底座 footprint**（座位、实际方块和路上方的空气列）钉平
  在基面高度；T1.5 里该 footprint 是最终求解中的一个**可升降平单元**，装饰随之
  落到落定的层级。底座参与求解——形状固定、可整体升降、表面取平。1×1 的 RIGID
  装饰件（灯）仍像以前一样随座位。
- 装饰只通过**自身底座 footprint 之外、水平（4）邻接的求解格**接入路网（座位也
  算格），每个这样的邻格都按半格规则校验；没有外部邻格的件计为孤立。其
  base group 只取 footprint 中与座位/实际底座格 4 连通的那部分，不连通的 bbox
  外圈无法把装饰拉离座位。
- 原版可能把装饰最底层方块（子 jigsaw 的 final 底座）留在街件座位上成为空气；
  writer 只补这一格（`/vps stats` 记 `base restored`），不移动装饰就补上灯座
  缺口。
- 街件座位之外的装饰（房屋灯座）成为**固定的非道路 fixture base cell**：求解器
  把四周道路重解到距底座半格以内（`/vps stats` 记 `fixture base cells`）。
  对角/草地座位因此是孤立的，不做高度联动。

**干草堆、树、花（`FeaturePoolElement`）由原版放置、不属于可竖向移动结构**：
不随座位升降、不钉座位、不被移动。干草堆真正放下的方块仍按位置保护，道路逐格
让位。

### 结构地面与道路重叠

同一列既被路格又被结构地面认领时，被认领列的原版 y=0 方块被抑制。参与重叠的
只有两类：**街件底座**，以及**原版固定形状农舍件**
（`village/<style>/[zombie/]houses/*farm*`，RIGID；整个 y=0 固定地面，含农田/
水渠/土径）。热带草原街道模板里的散装农田不参与，仍是街面景物。

同一来源结构的重叠列组成求解中的一个**可整体升降的平单元**，起点取结构地面
高度。writer 在解出高度写结构地面（而不是路），并按同一整格位移带上模板中地面
以上的方块（作物、底座），使道路与结构表面仍平滑相接。T1.5 下街件底座可整体
移动；T5 下底座物理固定（农舍地面由 writer 重写，仍随求解）。`/vps stats` 的
`fixture overlap cells`、`farm overlap cells` 与 `ground overlap written`
观测这一行为。

### 路肩包边与护栏

每条边都**从路块自身高度**起探测，向外两格一起探测（探2包1：探两格、包第 1 格）。

- **包边墙**。逐层检查：两探格任一格有碰撞形状或液体，第 1 格就包上该风格的
  石料（plains/snowy/taiga 圆石、desert 平滑砂岩、savanna 陶瓦）。原落差阈值
  （`kerb.minDropHeight`）仍然生效。第 1 格是空气时向上补到探测顶，一格退台
  变成挡土墙；材质不再限土类。建筑方块与一切非地形装饰（原木、树叶、花草、
  作物、藤蔓、家具、灯具、模组方块）都不替换：包边跳过装饰层并在此断开，带
  装饰的侧列截停墙体而不是被攀爬。两探格**任一格**在建筑保护范围内，该层即
  中断包边段，墙不再穿过建筑层。第 2 层两探格均"空置"（远处装饰视为没探到）时
  整墙不建——半砖路旁 1.5 格落差不再产生单格包边墙。道路有顶板（上限形成的
  屋顶或自然洞顶）时，墙在顶板下一格截止；开放天空仍包到侧列顶。
- **包边护栏**。每个连续包边段顶端放一层 persistent 树叶——地形顶端和每个柱中
  空隙顶端都放。不进入建筑，也不进入可移动建筑门前的 3×3（与落差护栏同一门口
  豁免）。因道路顶板或世界边界被截断的段不放截断顶叶。
- **广场内部**。指向 `town_centers` 件自身 y=0 足迹的一侧——井/喷泉水格和
  jigsaw 洞格，均非路格——不包边、不放护栏，因此包边不会糊住中心水井。足迹只
  登记模板**真实的 y=0 方块**（原版把空气也存成 palette 条目，这些空角不算），
  从模板空角上方经过的架空路恢复正常的包边与护栏。广场外边界不受影响。
- **端帽（收口）**。道路继续延伸时，包边墙沿路方向的末端**只按外侧那格**（能看到
  天空的格）判定露天：该格在当前墙顶以上完全无地形时才算开放。端帽写在
  **墙端本列**，从墙顶上一格起按同样的探2包1向上——包到本列与外侧探测列的地形
  顶，每段顶端放包边护栏。端帽不写进下一道路格的侧列（那是它自己的落差护栏
  目标）、不从路面重新填柱；横跨道路的端墙不补侧列；真正的道路尽头（没有下一格）
  不处理。
- **落差护栏**。从路缘**向下**扫描到第一个可站立方块：道路高出它**至少 2 整格**
  时，在路缘、路块高度 +1 处放 persistent 树叶（plains 橡木、desert/savanna
  金合欢、snowy/taiga 云杉）；目标格有受保护装饰时改为跳过。街道景物列（农田、
  渠水、陶瓦）走同一扫描判定，因此架空路从其上方经过时也放护栏——只有包边仍
  不伸入景物。

每个路格各自打理自己的边缘：一条低路和一条高路共用的列，会同时出现低路的包边
和高路的护栏。

### 包顶与照明

道路低于地面超过清方上限（`maxClearLayers`，默认 4）时改为隧道并生成顶板。

- **包顶**。包顶只探测路面本列，用同样的碰撞/液体判据，清方终点在写入时从真实
  柱重读。**只处理顶板最低一格**——其上的屋顶厚度保持原样。
- **隧道口**。4 邻格中有**路格**（沿路或横向）在其自身路面以上见天时，顶板末端
  就在路列内向上转成包边面：从包顶层上一格包到该列地形顶，每段顶端放护栏。
  即使向上包 **0 格**——本列顶板上方无地形，或首层即被保护——末端也在顶板上一格
  尝试放树叶。两探格任一格在建筑保护范围内，该面向上包同样中断。露天格必须仍在
  路网内：离开道路的露天格旁边已有道路自己的侧向包边，再向上包就成了
  "包边上再包边"。探2包1照常：第 1 格是路列/转上来的面，第 2 格是**往山体里退
  一格**（露天格的反方向，沿路或横向），不会探回露天格本身。两探格都是空气的层
  保持空气，因此不会悬空放圆石。
- **照明**。到达上限形成的顶板，最低格在三格宽直路的中间格换成**荧石**。超过
  上限的自然洞顶，最低格保留包边材质，并在上限格挂**灯笼**、用**铁链**连到洞顶。
  侧列、非三格宽、拐角和路口不做照明。顶板最低格是非地形装饰时整列跳过包顶
  处理；受保护的灯笼/铁链条目单独跳过。

### 过水段脚手架

路块处或其正下方有水的列改为 `scaffolding`：有水处 `waterlogged=true`，下方
方块完全支撑时 `distance=0`、否则 `distance=1`，`bottom` 按下方方块。脚手架
**就是**过水段的行走面——它在解出高度替换路块，过水段读起来像木板桥。脚手架是
整块方块，解出面为半砖台阶的过水格会高出半格：这是"看得见的桥"的既定代价。
三种情形（水在路块/水下/干燥）在 `/vps stats` 分别计数。

### 装饰一律保留

writer 对每个将要替换的方块按原版自然地形标签分类。原木、树叶、花草、作物、
藤蔓、家具、灯具以及一切未知/模组方块都算受保护装饰：路块、垫方、向上清方、
包边、包顶、灯笼/铁链和护栏全部逐格跳过、原地保留。只有自然地形和 mod 自己的
路面结构材料（泥砖、平滑砂岩、默认圆石包边、脚手架、土径垫方）会被清除、填方
或包边；路面材料保持可替换，同列"低路包边 + 高路护栏"才仍成立。

响应刻意逐格进行：树正好长在路列里就保留那一格、道路在那里让位——这是
"装饰赢"的既定行为，不是漏铺路。跳过的方块数按类别列在 `/vps stats` 的
`feature` 行。调试门牌/缝牌是唯一例外：为了可见性会替换目标格。

街件装饰与干草堆适用同一规则，但按精确位置：装饰的实际模板方块（含圆石/雪
底座）和干草堆真正放下的方块**按位置**保护，不按 bbox 或潜在盒。干草堆在放置
时记录；它是原版 feature、不是可竖向移动结构，保持原版位置，writer 让位于其
实际方块。

## 路是本 mod 写的，不是覆盖出来的

原版先放村庄：街道模板由原版 `GravityProcessor` 贴到真实地形上，mod 只能在其
之后重写。事后重写有两个漏网窗口——剖面上方 9-10 格或下方 7-8 格——那些列会
留下**上下两层路**。

本 mod 现在**让原版在认领列上根本不放置路层**：挂进放置链，认领列的原版路块在
写入前就被丢弃，路块由 mod 落一次。mod 未认领的列——高度探测失败、或达到每村
上限——保留原版路，因此探测失败绝不会在世界里留洞。非村庄结构和已禁用的世界
完全不受影响。

`/vps stats` 同时打印两侧（`dropped`、`writes`、`delta`、
`yielded to buildings`），进游戏即可确认两边对账。delta 为正不一定是洞：座位、
广场、底座和结构地面重叠本来就不是普通路写入，各自由单独条目计数。桥面下方
挖开不会见到残留土径。

## 僵尸村庄整村排除

僵尸村庄（`minecraft:village/<style>/zombie/...`）**整村排除**在道路平滑之外。
mod 在结构开始处检测模板路径里的 `/zombie/`，在求解前直接返回：不占路网、不
抑制原版 y=0 街道层、不移动建筑、不执行 writer，生成的僵尸村庄与原版完全一致。
这不是逐格降级：只要该 start 的任意一个 piece 属于 zombie 模板，整个 start 都
不处理。

## 原理

原版街道用 `terrain_matching` 投影：`GravityProcessor` 把模板每一列独立贴到
高度图上，地形一跳路面就跳。

本 mod 在村庄拼装期（`Structure#generate` 内、包围盒冻结前）做一次
**T1.5 前移决策**：

1. 从街道件模板重建**路面掩膜**——从不扫描世界，因为原版街道处理器会随机把
   路面挖成草洞。掩膜取与 y=1 街道 jigsaw 连接点连通的街面；模板内的农田/水渠/
   陶瓦保持原版，连接点下的普通 dirt 仍算路。
2. 探测**噪声地形**——x/z 的纯函数，因此决策确定。
3. 把掩膜分解为窄**臂**（精确切片 DP）与宽**域**（平台初始化 + 行列迭代优化），
   求出相邻格落差 ≤ 半格的剖面。**没有独立参考剖面**：偏差直接对原始地形量——
   每列探得的行走面。候选值来自两条沿地形合法追线围成的包络加本列探测高度
   （地形追线候选带）；末段候选带沿合法坡度锥向区域接缝界延伸，合法坡道总是
   可达，离群方向变成带内偏移而不是整高接缝悬崖。过水列把水面作为首选高度而非
   固定锚：更平的解可以偏离水面，每个偏离格都计数（`water anchor deviations`）。
4. 每个可移动 RIGID 组件按主门平移到剖面上——同步 jigsaw junction、世界高度
   钳制、与**其他建筑**的重叠守卫（街道和收尾件不算障碍）。随后按移动后的足迹
   再解一次路，让高度探针补偿到建筑真正所在的位置；再做第二次权威对齐，把组件
   对齐到最终路网并冻结道路。解缓存到结构实例。

到落位期，本区块内的路格被重写为台阶/填方/挖方/包边/护栏/脚手架，诊断守卫
统计悬空/深埋建筑。`roadShapeStage=T5` 时退回落位期用真实高度图求解、不平移
建筑。

## 配置

`config/village_path_smoothed.json`，用 `/vps config reload` 重载（需要 op
权限）。主要项：

| 选项 | 默认值 | 含义 |
|---|---|---|
| `enabled`（全局） | `true` | 仅作播种默认值：创建世界时没动过创建界面开关的世界以此起步。每个世界自己的开关存在 `<世界>/village_path_smoothed.json` 并覆盖它；游戏内用 `/vps world on\|off` 切换。 |
| `roadSmoothing.objective` | `SMOOTH_FIRST` | `SMOOTH_FIRST` 按断崖惩罚 > 总台阶数 > 地形偏差排序；`MIN_DEVIATION` 把偏差与台阶数加权合并；`SHORTEST_CATCHUP` 贴地并在合法台阶内尽快追上；`HYBRID` 混合两者（`hybridWeightDeviation`）。 |
| `roadSmoothing.roadShapeStage` | `T1_5` | `T1_5` 在结构拼装期求解剖面并平移建筑；`T5` 是旧的落位期求解，不平移建筑（回退 / A-B 对比用）。 |
| `roadSmoothing.maxBuildingShift` | `0` | 建筑组件竖向平移上限（格）（`0` = 不限，仅受世界高度钳制）。 |
| `roadSmoothing.buildingShiftMedianWingBlocks` | `0` | 可选的双翼限制：`> 0` 时把最终位移钳制在旧中位数方案位移的该格数以内（`0` = 关）。 |
| `roadSmoothing.buildingGuard` | `true` | 仅诊断：在 `/vps stats` 统计悬空/深埋的已移动组件；从不修复、从不回退。 |
| `roadSmoothing.beardCompensation` | `0` | 旧参数：建筑旁噪声探测附加的格数。+1 档虽然补偿了 beard，但会让门口落在一个真实高度图列没有的 1 格凸块上——保持 0，仅 A-B 对比时调高（`< 0` 或 `0` 关闭；两种核模式均适用）。 |
| `roadSmoothing.beardRadius` | `4` | 旧参数：该 beard 区绕建筑足迹的水平半径（仅 step 核模式）。 |
| `roadSmoothing.beardKernel` | `step` | beard 补偿的形状：`step` = `beardRadius` 内平推 +1；`beard_thin` = 原版真实闭式（建筑基面以上削、以下填）——实验性，未标定。 |
| `roadSmoothing.beardKernelBlocksPerDensity` | `1.0` | 仅 `beard_thin`：每单位原版 beard 密度对应的表面方块数；尚未标定。 |
| `roadSmoothing.allowCutIntoTerrain` | `true` | 允许道路挖入山坡（下沉路段）。 |
| `roadSmoothing.stepViolationPenalty` | `32` | 每超出半格落差的软约束惩罚（断崖兜底）；残差计入 `/vps stats`。 |
| `roadSmoothing.dpWindowHalfUnits` | `16` | 每格候选半窗（半格为单位；宽切片自动收缩）。 |
| `roadSmoothing.maxExactSectionWidth` | `4` | 精确 DP 求解的切片宽度；更宽的区域用迭代优化。 |
| `roadSmoothing.roadSurfaceDetection` | `TEMPLATE_Y0_SOLID` | 街面判定规则：`TEMPLATE_Y0_SOLID` = 与街道 jigsaw 连接点连通的 y0 表面（农田/水/陶瓦保持原版）；`TEMPLATE_Y0_ROAD_MATERIAL` = 仅该风格自己的路块（连接点格仍加入）。 |
| `roadSmoothing.maxFillLayers` | `3` | 路高于地面时的最大连续填方层数；超过则该格改为桥面（`< 0` = 不限）。只作用于写入端：它决定已定高度的路如何输出（垫方 vs 桥面），从不影响求解。 |
| `roadSmoothing.maxClearLayers` | `4` | 路低于地面时向上清方的最大层数；超过则该格成隧道并生成顶板（`< 0` = 不限）。只作用于写入端，同 `maxFillLayers`。默认 4 让上限成顶与照明可见。 |
| `kerb.minDropHeight` | `1` | "侧向地形高出路面 N+1 整格"触发包边（行走面按半格比较）。 |
| `kerb.replaceableBlocks` | `["#minecraft:dirt"]` | 旧/兼容列表；包边的逐层触发与替换现已用碰撞/液体判据、不再限制材质，但仍跳过所有非地形装饰。 |
| `waterCrossing.enabled` | `true` | 脚手架桥；关闭则水面路段保持原版。 |
| `debug.doorSigns` | `false` | 可选调试门牌（主门 → 路格、解出面、实际地板、`NO FRONT`）。 |
| `debug.seamSigns` | `false` | 可选调试缝牌（每个求解掩膜接缝一块；半格保证被打破时标注残差原因）。 |
| `diagnostics.dumpRoadNetwork` | `false` | 每个求解完的村打一行日志。 |

## 命令

- `/vps world on|off|show` — 为执行者所在世界启用/禁用/查看道路平滑（每世界
  开关）。
- `/vps config show|reload` — 打印/重载配置。
- `/vps stats` — 求解村数、平均求解耗时、放置方块数；探测/写入诊断（含探测口径
  边界开关、对齐轮重写的失配列）；求解残差诊断（候选矛盾、残余台阶违例及最差
  台阶、水面锚点偏离）；原版方块抑制/对账计数（`dropped`、`writes`、`delta`、
  `yielded to buildings`、`zombie placements excluded`）；`feature` 行（保留的
  受保护装饰方块，按路/垫方/清方/包边/包顶/护栏分类）；`decor` 行（识别与被排除
  出 plan A 的装饰件、实际方块、base group 与格数、落定件数、受保护写入、干草堆
  方块、钉定格、座位同步与道路失配计数、孤立座位、resolve failed）；以及退化为
  单一区域的村庄。
- `/vps dump [radius]` — 重建并重解附近村庄的路网，打印格/臂/域数量（诊断）。
- `/vps debug villagerbrain freeze on|off` — 冻结村民，便于查看生成的道路。
  状态保存到全局配置、下一 tick 生效；冻结状态与跳过次数也显示在 `/vps stats`
  末尾。

## 已知问题

1. **脚手架桥会衰减**——`ScaffoldingBlock` 在放置后的第一个 tick 重新计算
   `distance`，无支撑的桥段会像原版脚手架一样弹掉。放置本身忠实于需求；加支撑
   柱或抑制复查留给后续版本。
2. **过水段可能有半格台阶**——脚手架是过水段的行走面且是整块方块，解出面为半砖
   台阶的过水格会高出半格，这是"看得见的桥"优于"藏起来的支撑块"的既定代价。
3. **沙漠村没有过水规则**——原版从不用木板替换沙漠村的水面路段，无物可换；那里
   砂岩路保持原版高度。
4. **包边只包地形、从不包装饰**——沙壁、雪层等自然地形都会包（不再限土类），
   外侧第 1 格为空气时也补成墙。受保护建筑格与一切非地形装饰都不替换；探测侧列
   里的装饰会中断包边段并跳过。writer 只跳过装饰那一格，因此树或其他 feature
   正好长在路块/垫方/清格列时会在那里留下缺格——这是"装饰赢"的既定行为，不是
   漏铺路。隧道照明只出现在三格宽直路的中间格（拐角/路口不做），且需要顶板
   （把 `maxClearLayers` 调到 0 以上才能看到上限成顶的情形）；最低顶板块是受
   保护装饰时会连带抑制包顶与灯笼/铁链。
5. **断崖取一次原版式跳格**——地形落差超过半格能力时，道路按软约束取最短跳格，
   而不是堆巨型填方；残差计入 `/vps stats`（`step violations`），绝不静默。
6. **建筑可能悬空或下沉**——"建筑随路"就是让坡地上的建筑随路升降；极端地形下
   组件可能悬空几格或深埋（`/vps stats` 计数，`buildingGuard`）。设计上接受
   （路面优先）；设 `roadShapeStage=T5` 可完全关闭平移。
7. **长坡由填/挖承载**——上限分别为 `maxFillLayers`/`maxClearLayers`（桥面/
   隧道）。超出上限的格**保留解算高度**、渲染成桥面或隧道，只计数
   （`fallback re-anchors`），writer 从不纠正求解器。非零计数说明这些列的探测
   或求解有偏差：carving 之上、以及 ±1 区块真实高度图窗口之外（T1.5 路径探测
   纯噪声），噪声高度可能差很多格，这些格会按设计表现为悬空桥面或敞口挖方。
8. **每世界开关只影响其后生成的区块**——启用/禁用边界一侧原版、一侧平滑，已
   生成的村庄永不回改。认领列路块写入失败时回退为在真实表面放路块，因此该问题
   表现为 `/vps stats` 的 `surface fallbacks` 而不是洞。
9. **每世界设置文件只在运行时使用**，自动化测试不覆盖；世界目录不可写时文件
   不会创建，该世界每次启动都沿用全局默认值。
10. **beard 补偿核仍是旧 `step` 近似**——真正的 `beard_thin` 闭式已实现并有
    单元测试，但密度-方块换算系数尚未实机标定，默认保持 `step`；标定前建筑
    周围可能有 ±1 残差。
11. **分离的路网分块求解**——原版会让一些支路穿过房屋（不在掩膜内），一个村
    可能有多个互不相连的街块；各自独立求解与写入，其间格子保留原版方块
    （`/vps stats` 记 `split masks`）。
12. **街面景物刻意不包边**——街道模板内的农田/水渠/陶瓦不是路；路切过田边时
    可能露出原始断面，属既定设计。架空路从其上方经过时仍放落差护栏，景物自身
    高度处不加任何东西。只有固定形状 `*_farm_*` 农舍件按解出高度重写。装饰与
    干草堆按实际方块保护；多格装饰的钉定可能在与自由路格衔接处留下计数可见的
    台阶（`/vps stats` 的 `decor` 行）。
13. **座位上的 feature 保持原版高度**——干草堆/树/花永不被移动；座位被平滑
    升降后，feature 可能悬空或陷入座位。writer 仍保护其实际方块，道路在那里
    留缺而不是覆盖它。
